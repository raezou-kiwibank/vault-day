# Scheduler & Job Orchestration API Reference

Quick, high-signal lookup card for listing schedules, checking execution jobs, and unpausing status tags.

---

### 📅 GET /v1/schedules (List Schedules)
Queries account or plan schedules generated by smart contract activation.

**Query Parameters:**
*   `resource.resource_id`: `string` (The account or plan ID, required)
*   `resource.resource_type`: `string` (Strictly `RESOURCE_TYPE_ACCOUNT` or `RESOURCE_TYPE_PLAN`, required)
*   `page_size`: `integer` (Strictly required and cannot be omitted or 0, e.g. `10`)

**Response Fields:**
*   `schedules`: `array` (List of schedule objects containing `id`, `status` [e.g. SCHEDULE_STATUS_COMPLETED], and `next_run_timestamp`)

---

### 📊 GET /v1/jobs (List Jobs)
Queries execution details for scheduled events.

**Query Parameters:**
*   `schedule_ids`: `string` (The ID of the parent schedule, required)
*   `page_size`: `integer` (Strictly required, e.g. `10`)

**Response Fields:**
*   `jobs`: `array` (List of job objects containing `id`, `status` [JOB_STATUS_SUCCEEDED, JOB_STATUS_PUBLISHED, JOB_STATUS_FAILED], and `schedule_timestamp`)

---

### 🏷️ POST /v1/account-schedule-tags (Create Schedule Tag)
Registers a schedule control tag. If `test_pause_at_timestamp` is set to a value in the past (e.g. `2020-01-01`), any schedules referencing this tag will be **paused** during creation.

**Request Payload:**
```json
{
  "request_id": "string (UUID, required)",
  "account_schedule_tag": {
    "id": "string (the tag ID, e.g. MY_PAUSE_TAG, required)",
    "description": "string (optional)",
    "test_pause_at_timestamp": "string (RFC3339 timestamp, optional)"
  }
}
```

---

### 🔓 PUT /v1/account-schedule-tags/{id} (Update Schedule Tag / Unpause)
Updates tag attributes. To resume or unpause any schedules referencing the tag, set `test_pause_at_timestamp` to `null` (None).

**Request Payload:**
```json
{
  "request_id": "string (UUID, required)",
  "account_schedule_tag": {
    "id": "string (the tag ID, required)",
    "test_pause_at_timestamp": null
  },
  "update_mask": {
    "paths": ["test_pause_at_timestamp"]
  }
}
```
