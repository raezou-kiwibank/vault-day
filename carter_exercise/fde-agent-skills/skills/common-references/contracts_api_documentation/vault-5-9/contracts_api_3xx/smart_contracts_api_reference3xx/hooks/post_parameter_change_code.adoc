= post_parameter_change_code
:status: hidden

pass:q[`post_parameter_change_code(old_parameter_values, updated_parameter_values, effective_date)`]  

Carries out actions required after a parameter change has occurred, such as amending a schedule. 

This hook only runs after INSTANCE level parameter changes.  

**Arguments**  

[width="100%", options="header"]
|===
|name|type|description
|old_parameter_values|Map[str, Union[Decimal, str, datetime, OptionalValue, UnionItemValue, int]]|All the old parameters values prior to the change.
|updated_parameter_values|Map[str, Union[Decimal, str, datetime, OptionalValue, UnionItemValue, int]]|Only the updated parameters values after the change.
|effective_date|datetime|The logical time the hook is being run. This is the time at which the new values became effective.
|===

**Return Type:**None
