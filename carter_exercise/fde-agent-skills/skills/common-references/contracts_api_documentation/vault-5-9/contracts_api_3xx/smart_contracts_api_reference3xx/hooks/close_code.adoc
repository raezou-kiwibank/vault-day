= close_code
:status: hidden

pass:q[`close_code(effective_date)`]  

Carries out actions when the account closes.

This hook runs after a request to set a Customer Account to pass:q[`ACCOUNT_STATUS_CLOSED`].  

**Arguments**  

[width="100%", options="header"]
|===
|name|type|description
|effective_date|datetime|The logical time the hook is being run.
|===
