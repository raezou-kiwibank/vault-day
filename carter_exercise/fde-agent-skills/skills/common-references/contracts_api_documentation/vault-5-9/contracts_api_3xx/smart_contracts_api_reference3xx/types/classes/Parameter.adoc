= Parameter
:status: hidden

pass:q[`Parameter`]  

A contract parameter.  

== Constructor:
pass:q[`Parameter(*, name, description, display_name, level, value, default_value, update_permission, derived, shape)`]  

Constructs a new Parameter.

|===
|name|type|description
|name|pass:q[`str`]| The name of the Parameter. This is how the Parameter is referred to programmatically by the Smart Contract when it fetches the Parameter value from the ParameterTimeseries. 
|description|pass:q[`Optional`][pass:q[`str`]]| The description of the Parameter. This may be used in a front-end user interface to show a user the meaning of the Parameter. 
|display_name|pass:q[`Optional`][pass:q[`str`]]|The display name of the Parameter. This may be used in a front-end                     user interface.
|level|pass:q[`Level`]|The level of the Parameter.
|value|pass:q[`Optional`][pass:q[`Union`][pass:q[`Decimal`], pass:q[`str`], pass:q[`datetime`], pass:q[`OptionalValue`], pass:q[`UnionItemValue`], pass:q[`int`]]]|The value of the Parameter.
|default_value|pass:q[`Optional`][pass:q[`Union`][pass:q[`Decimal`], pass:q[`str`], pass:q[`datetime`], pass:q[`OptionalValue`], pass:q[`UnionItemValue`], pass:q[`int`]]]| The default value of the Parameter. This is only applicable to INSTANCE level Parameters, and will only be used if an Account conversion performed via v1/account-migrations converts an Account to a Product Version that introduces this Parameter. |update_permission|pass:q[`UpdatePermission`]| Whether the user is allowed to update the Parameter or not. Only applicable to INSTANCE level Parameter objects.
