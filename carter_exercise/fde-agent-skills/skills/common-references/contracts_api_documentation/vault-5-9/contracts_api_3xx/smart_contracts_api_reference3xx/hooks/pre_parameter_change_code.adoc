= pre_parameter_change_code
:status: hidden

pass:q[`pre_parameter_change_code(parameters, effective_date)`]  

This hook is used to modify the Shape metadata of a parameter when updating pass:q[`INSTANCE`] level parameter values. Returns the dictionary of Smart Contract parameters to be used for new values' validation. Only parameter shape metadata fields can be changed. The hook can reject a parameter update by raising a Rejected error.  

**Arguments**  

[width="100%", options="header"]
|===
|name|type|description
|parameters|Map[str, Parameter]|The contract parameters. Any parameters changed will have the value field populated with the proposed value.
|effective_date|datetime|The logical time the hook is being run. This is the time at which the new values will become effective.
|===

**Return Type:**Map[str, Parameter]
