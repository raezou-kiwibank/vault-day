= notification_types
:status: hidden

An optional list of the Smart Contract, used to validate the notification type parameter in the link:{baseURL}/smart_contracts/contracts_api_3xx/smart_contracts_api_reference3xx/vault#instruct_notification[instruct_notification]{empty} directive.  

**Required**: False  

**Example**  
[source,python]
----
notification_types = ['statement_created', 'repayment_made']
----
