pass:q[`get_balance_timeseries(*, fetcher_id)`]  

Returns the link:./types#balancetimeseries[BalanceTimeseries]{empty} covering
all balances over the time period specified by the hook decorator. If a
duration is specified in the pass:q[`@requires`] decorator, the time window
size is in the range
pass:q[`[hook_effective_date - requirement_duration, hook_effective_date\]`]. If a
pass:q[`fetcher_id`] is specified in the
link:./account_fetcher_requirements#balances[balances]{empty} argument of the
pass:q[`@fetch_account_data`] decorator and passed as an argument in the function call,
then the time window is specified in the definition of the
link:./types#balancesintervalfetcher[BalancesIntervalFetcher]{empty} with the
specified pass:q[`fetcher_id`] in the link:./../smart_contracts_api_reference3xx/metadata#data_fetchers[data_fetchers]{empty} list
of the Contract metadata. If no hook decorator is provided, then an empty
result is returned if no pass:q[`fetcher_id`] is passed as an argument, otherwise an
pass:q[`InvalidSmartContractError`] is raised.
  

[width="100%", options="header"]
|===
|name|type|description
|fetcher_id|pass:q[`Optional`][pass:q[`str`]]| The id of the link:./types#balancesintervalfetcher[BalancesIntervalFetcher]{empty}. 1. Define the fetcher in the link:./metadata[Contract Metadata]{empty} link:./../smart_contracts_api_reference3xx/metadata#data_fetchers[data_fetchers]{empty} list. 2. Define the fetcher id in the balances argument in the pass:q[`@fetch_account_data`] decorator. If this function is called using a supervisee Vault object, the population of this argument will raise an pass:q[`InvalidSmartContractError`]. **Only available in version 3.10.0+**. 
|===

**Return Value:** pass:q[`BalanceTimeseries`]  

The Timeseries of the Balances.  

**Examples**  

An example with no decorator  

[source,python]
----

def execution_schedules(hook_arguments):
    # Returns empty results
    vault.get_balance_timeseries()
    # Raises InvalidSmartContractError
    vault.get_balance_timeseries(fetcher_id="fetcher_id")

----
An example with @requires decorator  

[source,python]
----

@requires(balances="1 month")
def execution_schedules(hook_arguments):
    # Returns BalanceTimeseries in required range
    vault.get_balance_timeseries()
    # Raises InvalidSmartContractError
    vault.get_balance_timeseries(fetcher_id="fetcher_id")

----
An example with @fetch_account_data decorator  

[source,python]
----

@fetch_account_data(balances=["fetcher_id"])
def execution_schedules(hook_arguments):
    # Raises InvalidSmartContractError
    vault.get_balance_timeseries()
    # Returns BalanceTimeseries in range defined in the fetcher
    vault.get_balance_timeseries(fetcher_id="fetcher_id")
    # Raises InvalidSmartContractError
    vault.get_balance_timeseries(fetcher_id="fetcher_not_in_decorator")
