= Development and testing

Developing Smart Contracts, Supervisor Contracts and Contract Modules that are based on the
Contracts Language API 3 is different to standard development because Smart Contracts cannot be
directly run locally. Smart Contracts are executed inside a custom-built environment according to
their specific API version.
