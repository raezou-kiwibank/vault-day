= RelativeDateTime
:status: hidden

pass:q[`RelativeDateTime`]

|===
|name|type|description

|find|pass:q[`Optional`][pass:q[`Union`][pass:q[`Next`], pass:q[`Previous`], pass:q[`Override`]]]| After the initial shift, alter the given values to find the appropriate datetime.
