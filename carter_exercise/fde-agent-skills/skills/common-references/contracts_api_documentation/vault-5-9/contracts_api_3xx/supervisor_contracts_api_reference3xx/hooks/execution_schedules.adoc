= execution_schedules
:status: hidden

pass:q[`execution_schedules()`]  

Returns the initial schedule for the pass:q[`scheduled_code`] hook.

At Plan's creation, this hook is called once only by Vault to determine at what times the pass:q[`scheduled_code`] hook should be called and with which pass:q[`event_type`] argument. The allowed keys and values can be seen link:https://apscheduler.readthedocs.io/en/latest/modules/triggers/cron.html[here]{empty}, though note that all values must be strings and any datetime value must be presented in link:https://en.wikipedia.org/wiki/ISO_8601[ISO 8601]{empty} format.  

**Return Type:**List[Tuple[str, Dict[str, str]]]
