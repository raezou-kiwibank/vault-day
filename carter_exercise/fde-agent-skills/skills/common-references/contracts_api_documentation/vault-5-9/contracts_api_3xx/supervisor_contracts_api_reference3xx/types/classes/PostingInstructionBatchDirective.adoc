= PostingInstructionBatchDirective
:status: hidden

pass:q[`PostingInstructionBatchDirective`]  


A link:#hookdirectives[HookDirective]{empty} that instructs a
link:#postinginstructionbatch[PostingInstructionBatch]{empty}.
**Only available in version 3.4.0+**.
  

== Constructor:
pass:q[`PostingInstructionBatchDirective(*, request_id, posting_instruction_batch)`]  

Constructs a new PostingInstructionBatchDirective  

[width="100%", options="header"]
|===
|name|type|description
|request_id|pass:q[`str`]| A unique ID generated by the client (payment processor) that is used for idempotency. 
|posting_instruction_batch|pass:q[`PostingInstructionBatch`]| An atomic batch of PostingInstructions that will be (or have been) all accepted or all rejected. Returns a List[PostingInstruction]. 
|===
