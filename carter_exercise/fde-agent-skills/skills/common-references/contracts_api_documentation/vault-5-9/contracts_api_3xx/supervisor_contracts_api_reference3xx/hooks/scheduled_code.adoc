= scheduled_code
:status: hidden

pass:q[`scheduled_code(event_type, effective_date)`]  

Carries out actions for the scheduled event type.  

**Arguments**  

[width="100%", options="header"]
|===
|name|type|description
|event_type|str|The event type for which the hook is being called. Event types are defined in the pass:q[`execution_schedules`] hook.
|effective_date|datetime|The logical time the hook is being run.
|===
