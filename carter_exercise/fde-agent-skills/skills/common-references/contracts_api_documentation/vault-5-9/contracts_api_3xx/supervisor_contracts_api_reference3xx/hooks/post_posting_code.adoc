= post_posting_code
:status: hidden

pass:q[`post_posting_code(postings, effective_date)`]  

**Only available in version 3.7+**: Carries out actions after a supervisee has decided whether to accept a batch of posting instructions in its pass:q[`pre_posting_code`] hook.

This hook is called after the accepted posting instructions were inserted into the Vault posting ledger.  

**Arguments**  

[width="100%", options="header"]
|===
|name|type|description
|postings|PostingInstructionBatch|The successful postings within PostingInstructionBatch.
|effective_date|datetime|The logical time the hook is being run.
|===

**Return Type:**None
