= EventTypeSchedule
:status: hidden

pass:q[`EventTypeSchedule`]  

The schedule definition associated with an Event Type. All schedule definition attributes must be based on the pass:q[`events_timezone`] field defined in the link:./../smart_contracts_api_reference3xx/metadata#events_timezone[Smart]{empty} and link:./../supervisor_contracts_api_reference3xx/metadata#events_timezone[Supervisor]{empty} Contract metadata. **Only available in version 3.8.0+**.  

== Constructor:
pass:q[`EventTypeSchedule(*, day, day_of_week, hour, minute, second, month, year)`]  

Constructs a new EventTypeSchedule. At least one of the optional attributes must be provided.  

[width="100%", options="header"]
|===
|name|type|description
|day|pass:q[`Optional`][pass:q[`str`]]|Day of the month (1-31).
|day_of_week|pass:q[`Optional`][pass:q[`str`]]|Day of the week (0-6 or mon-sun).
|hour|pass:q[`Optional`][pass:q[`str`]]|Hour (0-23).
|minute|pass:q[`Optional`][pass:q[`str`]]|Minute (0-59).
|second|pass:q[`Optional`][pass:q[`str`]]|Second (0-59).
|month|pass:q[`Optional`][pass:q[`str`]]|Month (1-12).
|year|pass:q[`Optional`][pass:q[`str`]]|Year (4-digit year).
|===
