pass:q[`InstructAccountNotificationDirective(*, account_id, notification_type, notification_details)`]  


A link:#hookdirectives[HookDirective]{empty} that instructs
the publication of a notification.
**Only available in version 3.12+**

|account_id|pass:q[`str`]|The Account ID of the account sending the notification.
|notification_type|pass:q[`str`]| The pass:q[`type`] of notification. Used to identify how a notification should be processed. 
|notification_details|pass:q[`Dict`][pass:q[`str`], pass:q[`str`]]| The information (key-value pairs of data) to be published with the notification.
