= Profit schedules

This section describes how you can use common Smart Contract patterns to implement and schedule the
payment of accrued profit on money deposited in a savings account

_Example:_ Profit accrued daily is paid into the customer account at the end of each month. The
first accrued profit payment is made one month after the account is opened.

_Step 1: Defining the schedule events_

Define two separate schedule events, with:

* The first schedule event handling daily profit accruals
* The second schedule event handling payment of the accrued profit

[source,python]
----
def execution_schedules():
    account_open_day = vault.get_account_creation_date()
    next_month = account_open_day + timedelta(months=1)
    apply_day = min(account_open_day.day, 28)
    return [
        ("APPLY_PROFIT", {
            "day": str(apply_day),
            "hour": '0',
            "start_date": f"{next_month.year}-{next_month.month}-{apply_day}"
            ),
        }),
        ("ACCRUE_PROFIT", {
            "hour": "23",
            "minute": '59'
        }),
    ]

@requires(event_type="ACCRUE_PROFIT", parameters=True, balances='latest')
@requires(event_type="APPLY_PROFIT", parameters=True, balances='latest')
def scheduled_code(event_type, effective_date):
    if event_type == "ACCRUE_PROFIT":
        _accrue_profit(vault, effective_date)

    elif event_type == "APPLY_PROFIT":
        _apply_profit(vault, effective_date)
----

For daily profit accruals, you need to define a dedicated `account_addresses` in the Smart Contract.
This will store the total accrued amount value and will be used to pay the profit into the customer
account.

The profit is accrued or paid from the bank's Internal Account to the customer account. The ID of
the bank's Internal Account is provided to the Smart Contract code using contract parameters.

Bank's Internal Account from which profit is accrued should be provided to the Smart Contract code
using contract parameters.

In the example below:

* The `"ACCRUED_INCOMING"` address is used in the customer's account to `store` the total accrued
value
* The `"ACCRUED_OUTGOING"` address is used in the bank's Internal Account

[NOTE]
====
* Profit can be accrued on any customer or bank's dedicated `account_addresses`.
* Profit rounding is not performed here. For further information, see the
link:{baseURL}/reference/contracts/contracts_api_3xx/common_examples#rounding_and_zeroing_out_interest[Rounding]
examples section.
====

_Step 2: Scheduling profit accrual_

Daily profit accrued on the total deposit balance is moved into the `"ACCRUED_INCOMING"` customer
account address from the bank's Internal Account `"ACCRUED_OUTGOING"` address.

[NOTE]
====
The example below does not show rounding as usually takes place when daily profit is calculated.
====

[source,python]
----
accrued_profit_account_address = "ACCRUED_INCOMING"
accrued_profit_banks_address = "ACCRUED_OUTGOING"

def _accrue_profit(vault, effective_date):
    denomination = vault.get_parameter_timeseries(name="denomination").latest()
    profit_rate = vault.get_parameter_timeseries(name="profit_rate").latest()
    internal_account = vault.get_parameter_timeseries(name="internal_account").latest()
    daily_rate = profit_rate / 365
    balance = vault.get_balance_timeseries().latest()[
        (DEFAULT_ADDRESS, DEFAULT_ASSET, denomination, Phase.COMMITTED)
    ].net
    profit_amount = daily_rate * balance

    if profit_amount > 0:
        posting_ins = vault.make_internal_transfer_instructions(
            amount=profit_amount,
            denomination=denomination,
            client_transaction_id=vault.get_hook_execution_id(),
            to_account_id=vault.account_id,
            to_account_address=accrued_profit_account_address,
            from_account_id=internal_account,
            from_account_address=accrued_profit_banks_address,
            pics=["PROFIT_ACCRUED"],
            instruction_details={"description": "Daily profit accrued"}
        )

        vault.instruct_posting_batch(
            posting_instructions=posting_ins, effective_date=effective_date
        )
----

_Step 3: Scheduling profit payment_ To apply monthly profit to a customer account, you need to:

* Get the total balance `"ACCRUED_INCOMING"` debited from the customer account address
* Credit to the `DEFAULT_ADDRESS` of the customer account
+
To move the profit from the Internal Account, you need to debit the balance from the
`"ACCRUED_OUTGOING"` account address to credit the `DEFAULT_ADDRESS`.

[NOTE]
====
The previous postings for this account debited the internal account, therefore the reversals must
credit the internal account.
====

[source,python]
----
accrued_profit_account_address = "ACCRUED_INCOMING"
accrued_profit_banks_address = "ACCRUED_OUTGOING"

def _apply_profit(vault, effective_date):
    posting_ins = []
    denomination = vault.get_parameter_timeseries(name="denomination").latest()
    internal_account = vault.get_parameter_timeseries(name="internal_account").latest()
    balances = vault.get_balance_timeseries().at(timestamp=effective_date)
    incoming_accrued = balances[
        (accrued_profit_account_address, DEFAULT_ASSET, denomination, Phase.COMMITTED)
    ].net

    if incoming_accrued > 0:
        # Fulfil any incoming profit into the account
        posting_ins.extend(
            vault.make_internal_transfer_instructions(
                amount=incoming_accrued,
                denomination=denomination,
                from_account_id=vault.account_id,
                from_account_address=accrued_profit_account_address,
                to_account_id=vault.account_id,
                to_account_address=DEFAULT_ADDRESS,
                asset=DEFAULT_ASSET,
                client_transaction_id="APPLY_ACCRUED_PROFIT_{}_CUSTOMER".credit
format(
                    vault.get_hook_execution_id()
                ),
                pics=["PROFIT_APPLIED"],
                instruction_details={
                    "description": "Monthly profit applied"
                }
            )
        )
        # Charge the profit from an internal account
        posting_ins.extend(
            vault.make_internal_transfer_instructions(
                amount=incoming_accrued,
                denomination=denomination,
                from_account_id=internal_account,
                from_account_address=DEFAULT_ADDRESS,
                to_account_id=internal_account,
                to_account_address=accrued_profit_banks_address,
                asset=DEFAULT_ASSET,
                client_transaction_id="APPLY_ACCRUED_PROFIT_{}_INTERNAL".format(
                    vault.get_hook_execution_id()
                ),
                pics=["PROFIT_APPLIED"],
                instruction_details={
                    "description": "Monthly profit applied"
                }
            )
        )

        vault.instruct_posting_batch(
            posting_instructions=posting_ins,
            effective_date=effective_date,
            client_batch_id="APPLY_ACCRUED_PROFIT_{}".format(
                vault.get_hook_execution_id()
            )
        )
