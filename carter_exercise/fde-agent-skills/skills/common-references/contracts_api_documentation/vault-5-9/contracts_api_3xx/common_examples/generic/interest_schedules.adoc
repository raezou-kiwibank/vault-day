= Interest schedules

This section describes how you can use common Smart Contract patterns to implement and schedule:

* The payment of interest on money deposited in a savings account; or
* How interest is charged on the outstanding balance of a loan made to a customer

_Example:_ Interest accrued daily is paid into the customer account at the end of each month. The
first interest payment is made one month after the account is opened.

_Step 1: Defining the schedule events_

Define two separate schedule events, with:

* The first schedule event handling daily interest accruals
* The second schedule event handling payment of the accrued interest

[source,python]
----
def execution_schedules():
    account_open_day = vault.get_account_creation_date()
    next_month = account_open_day + timedelta(months=1)
    apply_day = min(account_open_day.day, 28)
    return [
        ('APPLY_INTEREST', {
            'day': str(apply_day),
            'hour': '0',
            'start_date': '{}-{}-{}'.format(
                next_month.year,
                next_month.month,
                apply_day
            ),
        }),
        ('ACCRUE_INTEREST', {
            'hour': '23',
            'minute': '59'
        }),
    ]

@requires(event_type='ACCRUE_INTEREST', parameters=True, balances='latest')
@requires(event_type='APPLY_INTEREST', parameters=True, balances='latest')
def scheduled_code(event_type, effective_date):
    if event_type == 'ACCRUE_INTEREST':
        _accrue_interest(vault, effective_date)

    elif event_type == 'APPLY_INTEREST':
        _apply_interest(vault, effective_date)
----

For daily interest accruals, you need to define a dedicated `account_addresses` in the Smart
Contract. This will store the total accrued amount value and will be used to pay the interest into
the customer account.

The interest is accrued or paid from the bank's Internal Account to the customer account. The ID of
the bank's Internal Account is provided to the Smart Contract code using contract parameters.

Bank's Internal Account from which interest are accrued, should be provided to the Smart Contract
code using contract parameters.

In the example below:

* The `'ACCRUED_INCOMING'` address is used in the customer's account to `store` the total accrued
value
* The `'ACCRUED_OUTGOING'` address is used in the bank's Internal Account

[NOTE]
====
* Interest can be accrued on any customer or bank's dedicated `account_addresses`.
* Interest rounding is not performed here. For further information, see the
link:{baseURL}/reference/contracts/contracts_api_3xx/common_examples#rounding_and_zeroing_out_interest[Rounding]
examples section.
====

_Step 2: Scheduling interest accrual_

Daily interest accrued on the total deposit balance is moved into the `'ACCRUED_INCOMING'` customer
account address from the bank's Internal Account `'ACCRUED_OUTGOING'` address.

[source,python]
----
accrued_interest_account_address = 'ACCRUED_INCOMING'
accrued_interest_banks_address = 'ACCRUED_OUTGOING'

def _accrue_interest(vault, effective_date):
    denomination = vault.get_parameter_timeseries(name='denomination').latest()
    interest_rate = vault.get_parameter_timeseries(name='interest_rate').latest()
    internal_account = vault.get_parameter_timeseries(name='internal_account').latest()
    daily_rate = interest_rate / 365
    balance = vault.get_balance_timeseries().latest()[
        (DEFAULT_ADDRESS, DEFAULT_ASSET, denomination, Phase.COMMITTED)
    ].net
    interest_amount = daily_rate * balance

    if interest_amount > 0:
        posting_ins = vault.make_internal_transfer_instructions(
            amount=interest_amount,
            denomination=denomination,
            client_transaction_id=vault.get_hook_execution_id(),
            to_account_id=vault.account_id,
            to_account_address=accrued_interest_account_address,
            from_account_id=internal_account,
            from_account_address=accrued_interest_banks_address,
            pics=['INTEREST_ACCRUED'],
            instruction_details={'description': 'Daily interest accrued'}
        )

        vault.instruct_posting_batch(
            posting_instructions=posting_ins, effective_date=effective_date
        )
----

_Step 3: Scheduling interest payment_ To apply monthly interest to a customer account, you need to:

* Get the total balance `'ACCRUED_INCOMING'` from the customer account address
* Move it to the `DEFAULT_ADDRESS` of the customer account To move the interest from the Internal
Account, you need to:
* Move the balance from the `'ACCRUED_OUTGOING'`account address to the `DEFAULT_ADDRESS` address

[NOTE]
====
As the balance in the Internal Account is negative, this requires the internal transfer instruction
to be reverse (see example below).
====

[source,python]
----
accrued_interest_account_address = 'ACCRUED_INCOMING'
accrued_interest_banks_address = 'ACCRUED_OUTGOING'

def _apply_interest(vault, effective_date):
    posting_ins = []
    denomination = vault.get_parameter_timeseries(name='denomination').latest()
    internal_account = vault.get_parameter_timeseries(name='internal_account').latest()
    balances = vault.get_balance_timeseries().at(timestamp=effective_date)
    incoming_accrued = balances[
        (accrued_interest_account_address, DEFAULT_ASSET, denomination, Phase.COMMITTED)
    ].net

    if incoming_accrued > 0:
        # Fulfil any incoming interest into the account
        posting_ins.extend(
            vault.make_internal_transfer_instructions(
                amount=incoming_accrued,
                denomination=denomination,
                from_account_id=vault.account_id,
                from_account_address=accrued_interest_account_address,
                to_account_id=vault.account_id,
                to_account_address=DEFAULT_ADDRESS,
                asset=DEFAULT_ASSET,
                client_transaction_id='APPLY_ACCRUED_INTEREST_{}_CUSTOMER'.format(
                    vault.get_hook_execution_id()
                ),
                pics=['INTEREST_APPLIED'],
                instruction_details={
                    'description': 'Monthly interest applied'
                }
            )
        )
        # Charge the interest from an internal account
        posting_ins.extend(
            vault.make_internal_transfer_instructions(
                amount=incoming_accrued,
                denomination=denomination,
                from_account_id=internal_account,
                from_account_address=DEFAULT_ADDRESS,
                to_account_id=internal_account,
                to_account_address=accrued_interest_banks_address,
                asset=DEFAULT_ASSET,
                client_transaction_id='APPLY_ACCRUED_INTEREST_{}_INTERNAL'.format(
                    vault.get_hook_execution_id()
                ),
                pics=['INTEREST_APPLIED'],
                instruction_details={
                    'description': 'Monthly interest applied'
                }
            )
        )

        vault.instruct_posting_batch(
            posting_instructions=posting_ins,
            effective_date=effective_date,
            client_batch_id='APPLY_ACCRUED_INTEREST_{}'.format(
                vault.get_hook_execution_id()
            )
        )
----

[NOTE]
====
You can use similar code where a customer is charged interest, for example, on a loan. You will need
to switch the direction of internal transfers and the account addresses for the customer account and
the bank's Internal Account.
====
