= supervisees
:status: hidden

pass:q[`Dict[str, Vault\]`]
 A dictionary which maps the supervised Account IDs to their link:./../smart_contracts_api_reference4xx/vault[Vault]{empty} objects. These objects can be used to retrieve account data, and to retrieve or commit Hook Directives. The allowed API functions of the Supervisee Vault objects per hook can be found link:./../smart_contracts_api_reference4xx/hooks[here]{empty}.
