= data_fetchers
:status: hidden

An optional list of the Supervisor Contract data fetchers. The fetcher IDs of the same fetcher type must be unique. The classes of the fetchers allowed in this list, named with the pattern [FetcherType]Fetcher, can be found link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes[here]{empty}. You can define the IDs of the fetchers in the arguments of the pass:q[`@fetch_account_data`] link:{baseURL}/smart_contracts/contracts_api_4xx/supervisor_contracts_api_reference4xx/account_fetcher_requirements[decorator]{empty}, to request hook data based on these fetchers. For more information, see our performance considerations for link:{baseURL}/smart_contracts/contracts_api_3xx/performance_considerations#optimised_smart_contract_data_fetching[optimised data fetching]{empty}. Note that the datetimes of the fetchers are evaluated in UTC, regardless of the Plan's link:{baseURL}/smart_contracts/contracts_api_4xx/supervisor_contracts_api_reference4xx/vault#events_timezone[events_timezone]{empty}.  

**Required**: False  

**Example**  
[source,python]
----
data_fetchers = [
    BalancesIntervalFetcher(
        fetcher_id='bif_1',
        start=RelativeDateTime(
            shift=Shift(years=-1, months=2),
            origin=DefinedDateTime.EFFECTIVE_DATETIME
        ),
        end=DefinedDateTime.EFFECTIVE_DATETIME
    ),
    BalancesObservationFetcher(
        fetcher_id='bof_1',
        at=RelativeDateTime(
            shift=Shift(months=-1),
            origin=DefinedDateTime.EFFECTIVE_DATETIME
        ),
        filter=BalancesFilter(addresses=['INTEREST', 'SAVINGS'])
    ),
    BalancesObservationFetcher(
        fetcher_id='lbof_1',
        at=DefinedDateTime.LIVE,
    )
]
----
