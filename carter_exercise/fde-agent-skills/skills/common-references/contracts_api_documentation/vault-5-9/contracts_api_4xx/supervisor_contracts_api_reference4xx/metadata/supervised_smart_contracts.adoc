= supervised_smart_contracts
:status: hidden

The set of Smart Contract Version IDs that can be onboarded to the Plan of the Supervisor Contract. This attribute is optional. If omitted, any Smart Contract can be onboarded and the pass:q[`overrides_event_types`] attribute in link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#supervisorcontracteventtype[Event Types]{empty} cannot be set.  

**Required**: False  

**Example**  
[source,python]
----
supervised_smart_contracts = [
  SmartContractDescriptor(alias='s1', smart_contract_version_id='smart_contract_version_id1', supervise_post_posting_hook=False,
                          supervised_hooks=SupervisedHooks(pre_posting_hook=SupervisionExecutionMode.OVERRIDE)),
  SmartContractDescriptor(alias='s2', smart_contract_version_id='smart_contract_version_id2', supervise_post_posting_hook=True,
                          supervised_hooks=SupervisedHooks(pre_posting_hook=SupervisionExecutionMode.INVOKED)),
]
----
