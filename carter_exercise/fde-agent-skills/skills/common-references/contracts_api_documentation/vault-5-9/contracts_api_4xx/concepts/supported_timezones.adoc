= Supported Timezones

Timezones are defined using IANA timezone IDs from the _tz database_.
The timezones that are supported within Smart or Supervisor Contracts are listed below.

Follow the links for more details on defining the timezone in the `events_timezone` metadata for
link:{baseURL}/reference/contracts/contracts_api_4xx/smart_contracts_api_reference4xx/metadata#events_timezone[Smart Contracts] and
link:{baseURL}/reference/contracts/contracts_api_4xx/supervisor_contracts_api_reference4xx/metadata#events_timezone[Supervisor Contracts].
