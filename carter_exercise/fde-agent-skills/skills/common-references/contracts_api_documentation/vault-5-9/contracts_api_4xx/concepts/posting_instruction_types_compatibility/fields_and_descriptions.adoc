=== unique_client_transaction_id

The globally unique ID of the `ClientTransaction` that this posting instruction is a part of. This
value is not deterministic; therefore, it is not guaranteed to be consistent between different
contract executions for the same `ClientTransaction`. A posting instruction may be viewed as a
