= data_fetchers
:status: hidden

An optional list of Smart Contract data fetchers.

The classes of the fetchers allowed in this list, defined using the pattern pass:q[`[FetcherType\]Fetcher`], can be found in link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes[Classes]{empty}.

The fetcher IDs of the same link:{baseURL}/smart_contracts/contracts_api_4xx/smart_contracts_api_reference4xx/account_fetcher_requirements[fetcher type]{empty} (postings, balances, etc) must be unique. If you're using link:{baseURL}/smart_contracts/contracts_api_4xx/smart_contracts_api_reference4xx/metadata#sub_account_types[sub_account_types]{empty}, every fetcher ID must be unique across *all* data fetchers.

To request hook data based on these fetchers, you can define fetcher IDs in the pass:q[`@fetch_account_data`] link:{baseURL}/smart_contracts/contracts_api_4xx/smart_contracts_api_reference4xx/account_fetcher_requirements[decorator]{empty} arguments. For more details about optimised data fetching, see link:{baseURL}/smart_contracts/contracts_api_4xx/concepts#optimised_data_fetching[Optimised data fetching]{empty} and link:{baseURL}/smart_contracts/contracts_api_4xx/performance_considerations#smart_contract_data_requirements[Smart Contract data requirements]{empty}. Note that the datetimes of the fetchers are evaluated in UTC, regardless of the Account's link:{baseURL}/smart_contracts/contracts_api_4xx/smart_contracts_api_reference4xx/vault#events_timezone[events_timezone]{empty}.  

**Required**: False  

**Example**  
[source,python]
----
data_fetchers = [
    BalancesIntervalFetcher(
        fetcher_id='bif_1',
        start=RelativeDateTime(
            shift=Shift(years=-1, months=2),
            origin=DefinedDateTime.EFFECTIVE_DATETIME
        ),
        end=DefinedDateTime.EFFECTIVE_DATETIME
    ),
    BalancesObservationFetcher(
        fetcher_id='bof_1',
        at=RelativeDateTime(
            shift=Shift(months=-1),
            origin=DefinedDateTime.EFFECTIVE_DATETIME
        ),
        filter=BalancesFilter(addresses=['INTEREST', 'SAVINGS'])
    ),
    BalancesObservationFetcher(
        fetcher_id='lbof_1',
        at=DefinedDateTime.LIVE,
    ),
    PostingsIntervalFetcher(
        fetcher_id='pif_1',
        start=RelativeDateTime(
            shift=Shift(years=-1, months=2),
            origin=DefinedDateTime.EFFECTIVE_DATETIME
        ),
    )
]
----
