pass:q[`activation_hook(vault, hook_arguments)`]  

Carries out any required actions when an account is opened, specifically when account.status is set to pass:q[`ACCOUNT_STATUS_OPEN`] via the link:{baseURL}/api/core_api#accounts[v1/accounts] or link:{baseURL}/api/core_api#accounts_v2[v2/accounts] endpoint.

When an account is opened, the pass:q[`effective_datetime`] will default to the timestamp when the request was processed. For /v1/accounts, this is set to the pass:q[`opening_timestamp`]. For /v2/accounts, this is set to the pass:q[`activation_timestamp`]. *Note*: If the pass:q[`effective_datetime`] is backdated in the request to open the account, the pass:q[`opening_timestamp`] (in v1) or pass:q[`activation_timestamp`] (in v2) will also backdate to this new timestamp.

If pass:q[`event_types`] are defined on a Smart Contract, this hook must be defined in order to activate an Account on that Smart Contract.

from dateutil.relativedelta import relativedelta
from contracts_api import (
    ActivationHookArguments,
    ActivationHookResult,
    ScheduledEvent,
    ScheduleExpression,
    ScheduledEventHookArguments,
    SmartContractEventType,
    Tside,
)

api = "4.0.0"
version = "1.0.0"
tside = Tside.ASSET

event_types = [
    SmartContractEventType(name="ACCRUE_INTEREST"),
    SmartContractEventType(name="APPLY_INTEREST"),
    SmartContractEventType(name="SERVICE_CHARGE"),
    SmartContractEventType(name="DAILY_CHECK"),
]


def activation_hook(vault, hook_arguments: ActivationHookArguments):
    return ActivationHookResult(
        scheduled_events_return_value={
            # 11:30:00 utc everyday
            "ACCRUE_INTEREST": ScheduledEvent(
                start_datetime=hook_arguments.effective_datetime,
                expression=ScheduleExpression(hour=11, minute=30),
            ),
            # 22:00:00 utc on the last day of every month
            "APPLY_INTEREST": ScheduledEvent(
                start_datetime=hook_arguments.effective_datetime,
                expression=ScheduleExpression(day="last", hour=22),
            ),
            # 23:00:00 utc on the 5th April
            "SERVICE_CHARGE": ScheduledEvent(
                start_datetime=hook_arguments.effective_datetime,
                expression=ScheduleExpression(month=4, day=5, hour=23),
            ),
            # 09:00:00 utc on everyday for one year
            "DAILY_CHECK": ScheduledEvent(
                expression=ScheduleExpression(hour=9),
                start_datetime=hook_arguments.effective_datetime,
                end_datetime=hook_arguments.effective_datetime + relativedelta(years=1),
            ),
        }
    )
