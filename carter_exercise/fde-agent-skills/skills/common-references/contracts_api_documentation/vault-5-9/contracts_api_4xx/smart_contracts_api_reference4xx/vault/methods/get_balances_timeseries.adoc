pass:q[`get_balances_timeseries(*, fetcher_id)`]  

Returns a Python mapping object, mapping
link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#balancecoordinate[BalanceCoordinate]{empty} to
link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#balancetimeseries[BalanceTimeseries]{empty} covering
the Account balances over the time period specified by the hook decorator.

There are three main scenarios where pass:q[`get_balances_timeseries`] can be
called and slightly different behaviors are expected for each:

**When called in a Smart Contract hook using pass:q[`@fetch_account_data`]
decorator**, a pass:q[`fetcher_id`] must be specified in the
link:./account_fetcher_requirements#balances[balances]{empty} argument of the
pass:q[`@fetch_account_data`] decorator and passed as an argument in the function call.
The time window is specified in the
link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#balancesintervalfetcher[BalancesIntervalFetcher]{empty} defined in the
link:{baseURL}/smart_contracts/contracts_api_4xx/smart_contracts_api_reference4xx/metadata#data_fetchers[data_fetchers]{empty} field in the Contract's metadata.
Raises an pass:q[`InvalidSmartContractError`] if the pass:q[`fetcher_id`] is not provided in the Smart Contract.

**When called in a Supervisor Contract hook using pass:q[`@fetch_account_data`]
decorator, on a Supervisee Vault object**, a pass:q[`fetcher_id`] must be passed as
an argument.

**When called in a Supervisor Contract hook using link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/decorators#requires[@requires]{empty}
decorator, on a Supervisee Vault object**, pass:q[`fetcher_id`] must not be passed as an argument. When
a duration is specified in the pass:q[`@requires`] decorator, the time window size is in
the range pass:q[`[hook_effective_date - requirement_duration, hook_effective_date\]`].

**Note:** for performance reasons, each timeseries is lazy evaluated. Whilst it
is possible, iterating over all keys/items is not recommended. If a given
pass:q[`BalanceCoordinate`] object does not exist in the mapping, an empty
pass:q[`BalanceTimeseries`] will be returned.
