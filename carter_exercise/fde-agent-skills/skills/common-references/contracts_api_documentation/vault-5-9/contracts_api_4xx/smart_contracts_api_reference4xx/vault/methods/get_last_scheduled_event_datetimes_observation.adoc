= get_last_scheduled_event_datetimes_observation

pass:q[`get_last_scheduled_event_datetimes_observation(*, fetcher_id)`]  

Returns the link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#lastscheduledeventdatetimesobservation[LastScheduledEventDateTimesObservation]{empty} at the
datetime defined by the
link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#lastscheduledeventdatetimesobservation[LastScheduledEventDateTimesObservationFetcher]{empty}
whose ID is provided in the
link:./account_fetcher_requirements#last_scheduled_event_datetimes[last_scheduled_event_datetimes]{empty} argument of the
pass:q[`@fetch_account_data`] decorator.

[IMPORTANT]
====
Existing Customer Accounts cannot be converted to a Smart Contract with
link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#lastscheduledeventdatetimesobservationfetcher[LastScheduledEventDateTimesObservationFetcher]{empty}
if their current Smart Contract is not already using it, due to data access limitations.
Future Vault Core improvements aim to address these limitations.
====
  

[width="100%", options="header"]
|===
|name|type|description
|fetcher_id|pass:q[`str`]| The ID of the link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#lastscheduledeventdatetimesobservationfetcher[LastScheduledEventDateTimesObservationFetcher]{empty}. 1. Define the fetcher in the link:./metadata[Contract Metadata]{empty} link:./../smart_contracts_api_reference4xx/metadata#data_fetchers[data_fetchers]{empty} list. 2. Define the fetcher ID in the last_scheduled_event_datetimes argument in the pass:q[`@fetch_account_data`] decorator. 
|===

**Return Value:** pass:q[`LastScheduledEventDateTimesObservation`]  


The observation which includes the last scheduled event datetimes and the datetime at
which the values apply.
  

**Examples**  

An example with pass:q[`@fetch_account_data`] decorator  

[source,python]
----

@fetch_account_data(last_scheduled_event_datetimes=["fetcher_id"])
def post_posting_hook(vault, hook_arguments):
    # Raises InvalidSmartContractError.
    vault.get_last_scheduled_event_datetimes_observation()
    # Returns LastScheduledEventDateTimesObservation for event types specified in the observation fetcher.
    vault.get_last_scheduled_event_datetimes_observation(fetcher_id="fetcher_id")
    # Raises InvalidSmartContractError.
    vault.get_last_scheduled_event_datetimes_observation(fetcher_id="fetcher_not_in_decorator")

----
