= event_types
:status: hidden

An optional list of link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#smartcontracteventtype[Smart Contract Event Types]{empty}and link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#smartcontractadjustmenteventtype[Smart Contract Adjustment Event Types]{empty}. If defined, each scheduled event returned by pass:q[`activation_hook`] or pass:q[`conversion_hook`] must be included in this list. Conversely, if pass:q[`event_types`] are defined on a Smart Contract, then pass:q[`activation_hook`] must be defined in order to activate an Account on that Smart Contract. Similarly, if pass:q[`event_types`] are defined, then pass:q[`conversion_hook`] must be defined in order to convert an Account to that Smart Contract.
All event names must be unique, regardless of whether they are pass:q[`SmartContractEventTypes`] or pass:q[`SmartContractAdjustmentEventTypes`]. More details can be found in link:{baseURL}/reference/scheduler[Scheduler]{empty} and link:{baseURL}/reference/adjustments[Adjustments]{empty}.  

**Required**: False  

**Example**  
[source,python]
----
event_types = [
    SmartContractEventType(
        name='ACCRUE_INTEREST'
    ),
    SmartContractAdjustmentEventType(
        name='APPLY_INTEREST',
        correction_point=AdjustmentCorrectionPoint(
            value_datetime=DefinedDateTime.EFFECTIVE_DATETIME,
            booking_datetime=DefinedDateTime.EFFECTIVE_DATETIME,
        ),
    ),
]
----
