= get_flags_observation
:status: hidden

pass:q[`get_flags_observation(*, fetcher_id)`]  

Returns the
link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#flagsobservation[FlagsObservation]{empty}
at the datetime defined by the
link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#flagsobservationfetcher[FlagsObservationFetcher]{empty}
whose ID is provided in the
link:./account_fetcher_requirements#flags[flags]{empty} argument of the
pass:q[`@fetch_account_data`] decorator.
  

[width="100%", options="header"]
|===
|name|type|description
|fetcher_id|pass:q[`str`]|The ID of the link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#flagsobservationfetcher[FlagsObservationFetcher]{empty}.
|===

**Return Value:** pass:q[`FlagsObservation`]  


The observation which includes the flag values and the datetime at which the values apply.
The flags attribute of the link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#flagsobservation[FlagsObservation]{empty}
has type defaultdict if the
link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#flagsobservationfetcher[FlagsObservationFetcher]{empty} did not
specify a link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#flagsfilter[FlagsFilter]{empty}. Otherwise, the flags
attribute has type dict, containing an entry for each of the flag definition ids specified
in the link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#flagsfilter[FlagsFilter]{empty}.
  

**Examples**  

An example with pass:q[`@fetch_account_data`] decorator  

[source,python]
----

@fetch_account_data(flags=["flags_observation_fetcher"])
def post_posting_hook(vault, hook_arguments):
    # Raises InvalidSmartContractError.
    vault.get_flags_observation()
    # Returns FlagsObservation for flags specified in the observation fetcher.
    vault.get_flags_observation(fetcher_id="flags_observation_fetcher")
    # Raises InvalidSmartContractError.
    vault.get_flags_observation(fetcher_id="fetcher_not_in_decorator")

----
