= post_parameter_change_adjustment_hook
:status: hidden

pass:q[`post_parameter_change_adjustment_hook(adjusted_vault, snapshot_vault, hook_arguments)`]  

Used to override the Business As Usual (BAU) logic on the link:{baseURL}/smart_contracts/contracts_api_4xx/smart_contracts_api_reference4xx/hooks#post_parameter_change_hook[post_parameter_change_hook]{empty} during the link:{baseURL}/reference/adjustments[Adjustments]{empty} process.

Calculates the delta between snapshot_vault and adjusted_vault.  

**Arguments**  

[width="100%", options="header"]
|===
|name|type|description
|adjusted_vault|link:./vault[Vault]{empty}|Contains the state of Vault Core at the time of the hook execution in the Adjustments timeline.
|snapshot_vault|link:./vault[Vault]{empty}|Contains the state of Vault Core at the time of the original hook execution. For more information, see link:{baseURL}/reference/adjustments#data_returned_by_snapshot_vault[Data returned by snapshot_vault]{empty}.
|hook_arguments|link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#postparameterchangeadjustmenthookarguments[PostParameterChangeAdjustmentHookArguments]{empty}.|Hook arguments for this hook
|===

**Return Type:**link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#postparameterchangeadjustmenthookresult[PostParameterChangeAdjustmentHookResult]{empty}.
