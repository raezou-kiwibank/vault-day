pass:q[`get_balances_observation(*, fetcher_id)`]  

Returns the link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#balancesobservation[BalancesObservation]{empty} at the
datetime defined by the
link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#balancesobservationfetcher[BalancesObservationFetcher]{empty}
whose ID is provided in the
link:./account_fetcher_requirements#balances[balances]{empty} argument of the
pass:q[`@fetch_account_data`] decorator.

 

[width="100%", options="header"]
|===
|name|type|description
|fetcher_id|pass:q[`str`]| The ID of the link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#balancesobservationfetcher[BalancesObservationFetcher]{empty}. +

 &#49;. The fetcher must be defined in the link:{baseURL}/smart_contracts/contracts_api_4xx/smart_contracts_api_reference4xx/metadata#data_fetchers[data_fetchers]{empty} field in the Contract's metadata. +

 &#50;. The fetcher ID must be defined in the pass:q[`balances`] argument in the pass:q[`@fetch_account_data`] decorator. 
|===

**Return Value:** pass:q[`BalancesObservation`]  


The link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#balancesobservation[BalancesObservation]{empty} which includes the
Account balances and the datetime at which the values apply.
