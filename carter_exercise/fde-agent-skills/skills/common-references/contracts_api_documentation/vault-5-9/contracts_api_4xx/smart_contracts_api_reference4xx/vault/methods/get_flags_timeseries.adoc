pass:q[`get_flags_timeseries(*, fetcher_id)`]  

Returns the
link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#flagvaluetimeseries[FlagValueTimeseries]{empty}
at the datetime defined by the
link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#flagsintervalfetcher[FlagsIntervalFetcher]{empty}
whose ID is provided in the
link:./account_fetcher_requirements#flags[flags]{empty} argument of the
pass:q[`@fetch_account_data`] decorator.
  

[width="100%", options="header"]
|===
|name|type|description
|fetcher_id|pass:q[`str`]|The ID of the link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#flagsintervalfetcher[FlagsIntervalFetcher]{empty}. If the provided pass:q[`fetcher_id`] is not defined in the pass:q[`@fetch_account_data`] decorator, an pass:q[`InvalidSmartContractError`] will be raised.
|===

**Return Value:** pass:q[`Union`][pass:q[`dict`][pass:q[`str`], pass:q[`FlagValueTimeseries`]], pass:q[`defaultdict`][pass:q[`str`], pass:q[`FlagValueTimeseries`]]]  


A dictionary mapping the flag definition ids to the FlagValueTimeseries. The dictionary
has type defaultdict if the
link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#flagsintervalfetcher[FlagsIntervalFetcher]{empty} did not specify
a link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#flagsfilter[FlagsFilter]{empty}. Otherwise, the dictionary has
type dict, containing an entry for each of the flag definition ids specified in the
link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#flagsfilter[FlagsFilter]{empty}. In either case, the default value
stored in the dictionary is a
link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#flagvaluetimeseries[FlagValueTimeseries]{empty} containing a
link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#timeseriesitem[TimeseriesItem]{empty} with value False effective
from the start time defined in the fetcher.
