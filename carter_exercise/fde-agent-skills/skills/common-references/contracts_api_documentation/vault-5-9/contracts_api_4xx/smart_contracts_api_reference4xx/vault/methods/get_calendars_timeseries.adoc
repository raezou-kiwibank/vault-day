= get_calendars_timeseries
:status: hidden

pass:q[`get_calendars_timeseries(*, fetcher_id)`]  

Returns the
link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#calendartimeseries[CalendarTimeseries]{empty}
for the interval defined by the
link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#calendarsintervalfetcher[CalendarsIntervalFetcher]{empty}
whose ID is provided in the
link:./account_fetcher_requirements#calendars[calendars]{empty} argument of the
pass:q[`@fetch_account_data`] decorator.
  

[width="100%", options="header"]
|===
|name|type|description
|fetcher_id|pass:q[`str`]|The ID of the link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#calendarsintervalfetcher[CalendarsIntervalFetcher]{empty}.
|===

**Return Value:** pass:q[`Dict`][pass:q[`str`], pass:q[`CalendarTimeseries`]]  


A dictionary mapping the calendar IDs to the CalendarTimeseries.
  

**Examples**  

An example with pass:q[`@fetch_account_data`] decorator  

[source,python]
----

@fetch_account_data(calendars=["calendars_interval_fetcher"])
def post_posting_hook(vault, hook_arguments):
    # Raises InvalidSmartContractError.
    vault.get_calendars_timeseries()
    # Returns Dict[str, CalendarTimeseries] for calendars specified in the interval fetcher.
    vault.get_calendars_timeseries(fetcher_id="calendars_interval_fetcher")
    # Raises InvalidSmartContractError.
    vault.get_calendars_timeseries(fetcher_id="fetcher_not_in_decorator")

----
