= post_parameter_change_hook
:status: hidden

pass:q[`post_parameter_change_hook(vault, hook_arguments)`]  

Carries out any required actions after any pass:q[`ExpectedParameter`] value (or an pass:q[`INSTANCE`] level Parameter value) update has occurred which affects an Account. 
[TIP]
====
Whether or not this hook is triggered depends on whether pass:q[`triggers_post_parameter_change_hook`] is specified, and if so, how it is set. For more information see link:{baseURL}/reference/parameters/using_core_api_parameters#behaviour_of_the_post_parameter_change_hook[Behaviour of the post_parameter_change_hook].
====

When set to trigger, this hook will run even if the new Parameter value is equal to the previous one. This hook does not run if any pass:q[`ExpectedParameter`] value is backdated, or when parameter values are specified in an account creation request.

from contracts_api import (
    DecimalConstraint,
    ExpectedParameter,
    PostParameterChangeHookArguments,
    PostParameterChangeHookResult,
    ScheduleExpression,
    SmartContractEventType,
    Tside,
    UpdateAccountEventTypeDirective,
)

api = "4.0.0"
version = "1.0.0"
tside = Tside.ASSET

# Using the pass:q[`expected_parameters`] syntax for Core API parameters.
expected_parameters = [
    ExpectedParameter(
        id="interest_accrual_hour",
        constraint=DecimalConstraint(min_value=0, max_value=23),
    ),
]

event_types = [
    SmartContractEventType(name="ACCRUE_INTEREST"),
]


def post_parameter_change_hook(vault, hook_arguments: PostParameterChangeHookArguments):
    updated_parameter_values = hook_arguments.updated_parameter_values

   if "interest_accrual_hour" in updated_parameter_values:
        interest_accrual_hour = updated_parameter_values["interest_accrual_hour"]
        update_event_type_directive = UpdateAccountEventTypeDirective(
            event_type="ACCRUE_INTEREST",
            expression=ScheduleExpression(hour=interest_accrual_hour, minute=0, second=0),
        )

       return PostParameterChangeHookResult(
            update_account_event_type_directives=[update_event_type_directive],
        )
