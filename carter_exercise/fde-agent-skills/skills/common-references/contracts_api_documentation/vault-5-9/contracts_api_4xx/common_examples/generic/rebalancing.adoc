= Re-Balancing

The customer may want to move money from a `DEFAULT` address to a custom address or addresses after
posting instructions are received. This lets the customer distribute the money in an account into
different 'pots'. For example, the customer could allocate spending into pots called 'HOUSING',
'RESTAURANTS', and 'TRAVEL', and savings into pots called 'EMERGENCY_FUND' and 'HOLIDAYS'. Using
these allocations helps simplify accounting and financial calculations in the Smart Contract code.
The following show some common examples of re-balancing.

== Re-balancing purchases

A credit card contract could have different types of transactions which would attract different
interest rates and fees on outstanding repayment amounts. These could have balance addresses, for
example, of:

* `ATM`
* `VIP_MERCHANTS`
* `ANY_MERCHANTS`
* `FEES`
* `INTEREST`

The bank could keep track of the different transactions the customer has performed by checking the
type in the instruction details metadata and then re-balancing.

_Example_: The bank only re-balances posting instructions with balances in
link:{baseURL}/reference/contracts/contracts_api_4xx/common_types_4xx/enums#phase[phase] `COMMITTED`, and
leaves balances in phase `PENDING_IN` or `PENDING_OUT` in the 'DEFAULT' address, and doesn't
re-balance repayments.

[NOTE]
====
For simplicity, we assume that all the posting instructions received by the hook have metadata
attached to them that contain the spending type related to the purchase. We also don't show how
interest and fees are charged, and the account type is 'LIABILITY'.
====

[source,python]
----
@requires(parameters=True)
def post_posting_hook(
    vault, hook_arguments: PostPostingHookArguments
) -> Optional[PostPostingHookResult]:
    denomination = vault.get_parameter_timeseries(name="denomination").at(
        at_datetime=hook_arguments.effective_datetime,
    )

    purchase_instructions_directives = []
    for posting_instruction in hook_arguments.posting_instructions:
        purchase_type = posting_instruction.instruction_details["purchase_type"]
        balance_coordinate = BalanceCoordinate(
            account_address=DEFAULT_ADDRESS,
            asset=DEFAULT_ASSET,
            denomination=denomination,
            phase=Phase.COMMITTED,
        )
        purchase_amount = posting_instruction.balances()[balance_coordinate].net
        if purchase_amount < Decimal("0"):
            # Re-balance credit card spending
            purchase_instructions_directives.append(
                # Transfer purchase funds internally
                PostingInstructionsDirective(
                    value_datetime=hook_arguments.effective_datetime,
                    posting_instructions=[
                        CustomInstruction(
                            postings=[
                                Posting(
                                    credit=False,
                                    amount=abs(purchase_amount),
                                    denomination=denomination,
                                    account_id=vault.account_id,
                                    account_address=purchase_type,
                                    asset=DEFAULT_ASSET,
                                    phase=Phase.COMMITTED,
                                ),
                                Posting(
                                    credit=True,
                                    amount=abs(purchase_amount),
                                    denomination=denomination,
                                    account_id=vault.account_id,
                                    account_address=DEFAULT_ADDRESS,
                                    asset=DEFAULT_ASSET,
                                    phase=Phase.COMMITTED,
                                ),
                            ],
                        ),
                    ],
                ),
            )

    # Submit re-balancing posting instructions directives, if any
    if purchase_instructions_directives:
        return PostPostingHookResult(
            posting_instructions_directives=purchase_instructions_directives,
        )
----

== Re-balancing repayments

_Example_: The loan contract has these customer addresses:

* `PRINCIPAL` balance for the total outstanding loan amount; this address is populated on account
activation using the `activation_hook` (not shown)
* `INTEREST` balance for the interest charged on the remaining loan amount; this address is
populated on a monthly schedule using the `scheduled_event_hook` (not shown)
* `FEES` balance for the fees charged for late repayments; this address is populated by a monthly
repayment check schedule (not shown)
* `DEFAULT` balance for the incoming posting instructions; this address is populated when the
customer performs transactions
* The bank follows this repayment hierarchy using re-balancing:
[arabic]
. `FEES`
. `INTEREST`
. `PRINCIPAL`

The account type is `ASSET` and all the customer account address balance net values are negative as
they store the amount the customer owes the bank.

[NOTE]
====
For simplicity, we assume that repayments will only be allocated to the outstanding balances with
phase `COMMITTED`. Balance amounts with phase `PENDING_IN` or `PENDING_OUT` are left in the
'DEFAULT' address. These addresses are already populated and we don't show how funds are charged for
them in the first place.
====

[source,python]
----
data_fetchers = [
    BalancesObservationFetcher(
        fetcher_id="bof_latest",
        at=DefinedDateTime.EFFECTIVE_DATETIME,
    ),
]

ACCOUNT_ADDRESSES = ["FEES", "INTEREST", "PRINCIPAL"]

@fetch_account_data(balances=["bof_latest"])
@requires(parameters=True)
def post_posting_hook(
    vault, hook_arguments: PostPostingHookArguments
) -> Optional[PostPostingHookResult]:
    denomination = vault.get_parameter_timeseries(name="denomination").at(
        at_datetime=hook_arguments.effective_datetime,
    )

    outstanding_balances = dict()
    latest_balances = vault.get_balances_observation(fetcher_id="bof_latest").balances
    balance_coordinate_default = BalanceCoordinate(
        account_address=DEFAULT_ADDRESS,
        asset=DEFAULT_ASSET,
        denomination=denomination,
        phase=Phase.COMMITTED,
    )
    for account_address in ACCOUNT_ADDRESSES:
        balance_coordinate_account_address = BalanceCoordinate(
            account_address=account_address,
            asset=DEFAULT_ASSET,
            denomination=denomination,
            phase=Phase.COMMITTED,
        )
        outstanding_balances[account_address] = latest_balances[
            balance_coordinate_account_address
        ].net

    repayment_posting_instructions_directives = []
    for repayment_posting_instruction in hook_arguments.posting_instructions:
        # This will process each repayment posting instruction, zeroing out the balances in
        # priority order
        remaining_repayment_amount = repayment_posting_instruction.balances()[
            balance_coordinate_default
        ].net

        if remaining_repayment_amount > Decimal("0"):
            for re_balancing_address in ACCOUNT_ADDRESSES:
                latest_address_balance = outstanding_balances[re_balancing_address]
                if latest_address_balance < Decimal("0"):
                    repayment_amount = min(remaining_repayment_amount, abs(latest_address_balance))
                    remaining_repayment_amount -= repayment_amount
                    repayment_posting_instructions_directives.append(
                        # Transfer repayment funds internally
                        PostingInstructionsDirective(
                            value_datetime=hook_arguments.effective_datetime,
                            posting_instructions=[
                                CustomInstruction(
                                    postings=[
                                        Posting(
                                            credit=False,
                                            amount=repayment_amount,
                                            denomination=denomination,
                                            account_id=vault.account_id,
                                            account_address=DEFAULT_ADDRESS,
                                            asset=DEFAULT_ASSET,
                                            phase=Phase.COMMITTED,
                                        ),
                                        Posting(
                                            credit=True,
                                            amount=repayment_amount,
                                            denomination=denomination,
                                            account_id=vault.account_id,
                                            account_address=re_balancing_address,
                                            asset=DEFAULT_ASSET,
                                            phase=Phase.COMMITTED,
                                        ),
                                    ],
                                ),
                            ],
                        ),
                    )
                    # Update balance value after the repayment
                    outstanding_balances[re_balancing_address] += repayment_amount
                if remaining_repayment_amount <= Decimal("0"):
                    break

    # Submit re-balancing posting instructions directives, if any
    if repayment_posting_instructions_directives:
        return PostPostingHookResult(
            posting_instructions_directives=repayment_posting_instructions_directives,
        )
