|event_type|pass:q[`str`]| The event type for which the hook is being called. Event types are defined in pass:q[`activation_hook`] and pass:q[`conversion_hook`]. 
|pause_at_datetime|pass:q[`Optional`][pass:q[`datetime`]]| The pass:q[`test_pause_at_timestamp`] attribute value set in link:{baseURL}/api/core_api#AccountScheduleTag[AccountScheduleTag]{empty} to pause the account scheduled events. Defaults to None, if the attribute is not set or the account link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#smartcontracteventtype[SmartContractEventType]{empty} has no pass:q[`scheduler_tag_ids`] applied. Note that if an account hook is triggered via a supervisor, then the supervisee pass:q[`pause_at_datetime`] has the value of pass:q[`test_pause_at_timestamp`] set on the supervisor scheduled event, which overrides the account event.
