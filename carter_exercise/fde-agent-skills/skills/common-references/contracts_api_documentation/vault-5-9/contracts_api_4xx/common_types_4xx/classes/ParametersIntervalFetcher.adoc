= ParametersIntervalFetcher
:status: hidden

pass:q[`ParametersIntervalFetcher`]  


Can only be used for pass:q[`ExpectedParameters`]. A fetcher for retrieving
parameter values over an interval, inclusive of end time. In the
pass:q[`activation_hook`], if any expected parameter values are provided in the account
creation request, these values will also be included in the parameter timeseries
of the fetcher with pass:q[`at_datetime`] equal to the hook pass:q[`effective_datetime`].
  

== Constructor:
pass:q[`ParametersIntervalFetcher(*, fetcher_id, start, end, filter)`]  

 

[width="100%", options="header"]
|===
|name|type|description
|fetcher_id|pass:q[`str`]|    The ID for this fetcher. This can be used in the    link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/decorators#fetch_account_data[@fetch_account_data]{empty} decorator    to request the data window defined in this fetcher. The fetcher ID must not start with an underscore.
|start|pass:q[`Union`][pass:q[`DefinedDateTime`], pass:q[`RelativeDateTime`]]|                   The start time of the interval window. This can either be a                   link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/enums#defineddatetime[DefinedDateTime]{empty}                   or a link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#relativedatetime[RelativeDateTime]{empty}.    Evaluated in UTC, regardless of the pass:q[`events_timezone`] of the   link:{baseURL}/smart_contracts/contracts_api_4xx/smart_contracts_api_reference4xx/vault#events_timezone[Account]{empty} or   link:{baseURL}/smart_contracts/contracts_api_4xx/supervisor_contracts_api_reference4xx/vault#events_timezone[Plan]{empty}. The pass:q[`DefinedDateTime.INTERVAL_START`], pass:q[`DefinedDateTime.LIVE`], and pass:q[`DefinedDateTime.ADJUSTMENT_EFFECTIVE_DATETIME`] enums are **not** allowed.                   If the value is of type pass:q[`RelativeDateTime`], its origin must be set to                   pass:q[`DefinedDateTime.EFFECTIVE_DATETIME`]. 
|end|pass:q[`Optional`][pass:q[`Union`][pass:q[`DefinedDateTime`], pass:q[`RelativeDateTime`]]]|     The end time of the interval window. Can either be defined relative to the effective time or    the interval start time (using    link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#relativedatetime[RelativeDateTime]{empty}), or as a time defined in Vault    Core (using link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/enums#defineddatetime[DefinedDateTime]{empty}).    Evaluated in UTC, regardless of the pass:q[`events_timezone`] of the    link:{baseURL}/smart_contracts/contracts_api_4xx/smart_contracts_api_reference4xx/vault#events_timezone[Account]{empty} or    link:{baseURL}/smart_contracts/contracts_api_4xx/supervisor_contracts_api_reference4xx/vault#events_timezone[Plan]{empty}.     If no end datetime is set or if it is set to pass:q[`None`], this will default to    link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/enums#defineddatetime[DefinedDateTime]{empty}.    If set to pass:q[`LIVE`], this will fetch data up to the hook's execution datetime. The value    pass:q[`DefinedDateTime.INTERVAL_START`] is **not** allowed. *Note*: if pass:q[`start`] is equal to pass:q[`end`], an error will be            raised at parse time. In addition, pass:q[`start`] and pass:q[`end`] timestamps are evaluated at the            execution time using the pass:q[`effective_datetime`] of the hook. If pass:q[`start`] is greater            than pass:q[`end`], an execution error is returned. The pass:q[`DefinedDateTime.ADJUSTMENT_EFFECTIVE_DATETIME`] enum is **not** allowed for pass:q[`at`] if pass:q[`at`] is a DefinedDateTime or pass:q[`at.origin`] if pass:q[`at`] is a RelativeDateTime. 
|filter|pass:q[`Optional`][pass:q[`ParametersFilter`]]| An optional filter to refine the results returned by the fetcher. If not provided, values will be fetched for all Expected Parameters defined in the contract. 
|===
