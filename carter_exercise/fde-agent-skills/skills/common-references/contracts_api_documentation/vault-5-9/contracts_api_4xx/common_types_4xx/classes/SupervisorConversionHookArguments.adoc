== Constructor:
pass:q[`SupervisorConversionHookArguments(*, effective_datetime, existing_schedules)`]  

Constructs a new SupervisorConversionHookArguments object.  

[width="100%", options="header"]
|===
|name|type|description
|effective_datetime|pass:q[`datetime`]|The logical datetime the hook is being run against. Must be a timezone-aware UTC datetime using the ZoneInfo class.
|existing_schedules|pass:q[`Dict`][pass:q[`str`], pass:q[`ScheduledEvent`]]| A dictionary of EventType name to ScheduledEvent, containing the existing ScheduledEvents associated with the contract. Does not include disabled schedules.
