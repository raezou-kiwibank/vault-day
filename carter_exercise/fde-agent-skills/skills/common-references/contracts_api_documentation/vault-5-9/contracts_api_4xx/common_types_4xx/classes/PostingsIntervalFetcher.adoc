= PostingsIntervalFetcher
:status: hidden

pass:q[`PostingsIntervalFetcher`]  


A fetcher for retrieving postings data within a given interval window, inclusive
of end time. Note that a pass:q[`PostingIntervalFetcher`] does not fetch postings that
are not committed yet.
  

== Constructor:
pass:q[`PostingsIntervalFetcher(*, fetcher_id, start, end)`]  

 

[width="100%", options="header"]
|===
|name|type|description
|fetcher_id|pass:q[`str`]| The ID for this fetcher. This can be used in the link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/decorators#fetch_account_data[@fetch_account_data]{empty} decorator to request the data window defined in this fetcher. 
|start|pass:q[`Union`][pass:q[`DefinedDateTime`], pass:q[`RelativeDateTime`]]|                   The start time of the interval window. This can either be a                   link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/enums#defineddatetime[DefinedDateTime]{empty}                   or a link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#relativedatetime[RelativeDateTime]{empty}.    Evaluated in UTC, regardless of the pass:q[`events_timezone`] of the   link:{baseURL}/smart_contracts/contracts_api_4xx/smart_contracts_api_reference4xx/vault#events_timezone[Account]{empty} or   link:{baseURL}/smart_contracts/contracts_api_4xx/supervisor_contracts_api_reference4xx/vault#events_timezone[Plan]{empty}. The pass:q[`DefinedDateTime.INTERVAL_START`], pass:q[`DefinedDateTime.LIVE`], and pass:q[`DefinedDateTime.ADJUSTMENT_EFFECTIVE_DATETIME`] enums are **not** allowed.                   If the value is of type pass:q[`RelativeDateTime`], its origin must be set to                   pass:q[`DefinedDateTime.EFFECTIVE_DATETIME`]. 
|end|pass:q[`Optional`][pass:q[`Union`][pass:q[`DefinedDateTime`], pass:q[`RelativeDateTime`]]]|     The end time of the interval window. Can either be defined relative to the effective time or    the interval start time (using    link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#relativedatetime[RelativeDateTime]{empty}), or as a time defined in Vault    Core (using link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/enums#defineddatetime[DefinedDateTime]{empty}).    Evaluated in UTC, regardless of the pass:q[`events_timezone`] of the    link:{baseURL}/smart_contracts/contracts_api_4xx/smart_contracts_api_reference4xx/vault#events_timezone[Account]{empty} or    link:{baseURL}/smart_contracts/contracts_api_4xx/supervisor_contracts_api_reference4xx/vault#events_timezone[Plan]{empty}.     If no end datetime is set or if it is set to pass:q[`None`], this will default to    link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/enums#defineddatetime[DefinedDateTime]{empty}.    If set to pass:q[`LIVE`], this will fetch data up to the hook's execution datetime. The value    pass:q[`DefinedDateTime.INTERVAL_START`] is **not** allowed. *Note*: pass:q[`start`] and pass:q[`end`] timestamps are evaluated            at the execution time using the pass:q[`effective_datetime`] of the hook. If pass:q[`start`] is            greater than pass:q[`end`], an execution error is returned. The pass:q[`DefinedDateTime.ADJUSTMENT_EFFECTIVE_DATETIME`] enum is **not** allowed for pass:q[`at`] if pass:q[`at`] is a DefinedDateTime or pass:q[`at.origin`] if pass:q[`at`] is a RelativeDateTime. 
|===
