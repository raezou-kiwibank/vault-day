= Next
:status: hidden

pass:q[`Next`]  


Alter the datetime by shifting to the next instance of the given parameter. This
object must include the pass:q[`day`] parameter, but all others are optional. Evaluated in UTC, regardless of the pass:q[`events_timezone`] of the link:{baseURL}/smart_contracts/contracts_api_4xx/smart_contracts_api_reference4xx/vault#events_timezone[Account]{empty} or the link:{baseURL}/smart_contracts/contracts_api_4xx/supervisor_contracts_api_reference4xx/vault#events_timezone[Plan]{empty}.
