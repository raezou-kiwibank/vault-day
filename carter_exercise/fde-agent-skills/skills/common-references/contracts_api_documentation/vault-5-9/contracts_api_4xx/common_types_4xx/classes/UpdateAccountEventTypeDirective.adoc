= UpdateAccountEventTypeDirective
:status: hidden

pass:q[`UpdateAccountEventTypeDirective`]  

A Hook Directive that instructs updating an Account Event Type.
                The Account Event Type can be either link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#smartcontracteventtype[SmartContractEventType]{empty} or
                 link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#smartcontractadjustmenteventtype[SmartContractAdjustmentEventType]{empty}.
