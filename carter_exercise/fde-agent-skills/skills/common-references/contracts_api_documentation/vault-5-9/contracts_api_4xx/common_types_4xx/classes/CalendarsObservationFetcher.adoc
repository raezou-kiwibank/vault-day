= CalendarsObservationFetcher
:status: hidden

pass:q[`CalendarsObservationFetcher`]  

A fetcher for observing calendars at a given moment in time. The pass:q[`filter`] attribute must be populated with a pass:q[`CalendarsFilter`] containing the calendar IDs to fetch for.   

== Constructor:
pass:q[`CalendarsObservationFetcher(*, fetcher_id, filter, at)`]  

Constructs a new CalendarsObservationFetcher object.  

[width="100%", options="header"]
|===
|name|type|description
|fetcher_id|pass:q[`str`]|The ID for this fetcher.
|filter|pass:q[`CalendarsFilter`]|A filter to refine the results returned by the fetcher.
|at|pass:q[`Union`][pass:q[`DefinedDateTime`], pass:q[`RelativeDateTime`]]|                    The time at which the calendars is observed.     Evaluated in UTC, regardless of the pass:q[`events_timezone`] of the    link:{baseURL}/smart_contracts/contracts_api_4xx/smart_contracts_api_reference4xx/vault#events_timezone[Account]{empty} or    link:{baseURL}/smart_contracts/contracts_api_4xx/supervisor_contracts_api_reference4xx/vault#events_timezone[Plan]{empty}. If the value is of type pass:q[`DefinedDateTime`], the following values are not allowed: pass:q[`DefinedDateTime.INTERVAL_START`], pass:q[`DefinedDateTime.ADJUSTMENT_EFFECTIVE_DATETIME`]. If the value is of type pass:q[`RelativeDateTime`], the following values are not allowed as the origin: pass:q[`DefinedDateTime.INTERVAL_START`], pass:q[`DefinedDateTime.ADJUSTMENT_EFFECTIVE_DATETIME`]. 
|===
