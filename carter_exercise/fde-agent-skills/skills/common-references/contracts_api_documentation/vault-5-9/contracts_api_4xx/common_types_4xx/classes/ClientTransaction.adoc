= ClientTransaction
:status: hidden

pass:q[`ClientTransaction`]  


A sequence of Posting Instruction objects with the same pass:q[`client_transaction_id`]
field.

This object represents the lifecycle of a single transaction. The lifecycle may be
as trivial as a single "hard settlement" (immediate movement of funds), or contain
any combination of authorisation, reauthorisation, and so on (see
link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/enums#postinginstructiontype[PostingInstructionType]{empty}).

Each Posting Instruction in this sequence represents a change in state in the
transaction's lifecycle.

Although the object schema allows for Posting Instruction objects within the same
link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/classes#clienttransaction[ClientTransaction]{empty}
to have differing pass:q[`account_id`], pass:q[`asset`], and pass:q[`denomination`] fields, by convention they
should all be the same, in which case the Posting Instruction only represents a
change to the net amount and/or link:{baseURL}/smart_contracts/contracts_api_4xx/common_types_4xx/enums#phase[Phase]{empty}
of its parent transaction.

|===

**Return Value:** pass:q[`BalanceDefaultDict`]  


The default balance dictionary where the key is the

credit and net balance changes. Accessing a non-existent key will return a
pass:q[`Balance`] object with zero debit, credit, and net balance changes.
