= CalendarEvent
:status: hidden

pass:q[`CalendarEvent`]  


A unique event resource defined in the Vault Calendar.
  

== Constructor:
pass:q[`CalendarEvent(*, id, calendar_id, start_datetime, end_datetime)`]  

 

[width="100%", options="header"]
|===
|name|type|description
|id|pass:q[`str`]| Uniquely identifies the Calendar Event in the Vault Calendar resource. 
|calendar_id|pass:q[`str`]| The ID of the Calendar that this Calendar Event belongs to. 
|start_datetime|pass:q[`datetime`]| The logical datetime at which the Calendar Event is effective from (inclusive). Must be a timezone-aware UTC datetime using the ZoneInfo class. 
|end_datetime|pass:q[`datetime`]| The logical datetime at which the Calendar Event is effective to (exclusive). Must be a timezone-aware UTC datetime using the ZoneInfo class. 
|===
