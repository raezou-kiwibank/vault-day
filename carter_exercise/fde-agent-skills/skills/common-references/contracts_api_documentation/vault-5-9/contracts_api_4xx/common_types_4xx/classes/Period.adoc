= Period
:status: hidden

pass:q[`Period`]  

The fixed time between balance observations in discrete interval fetchers. Exactly one of pass:q[`days`] or pass:q[`months`] must be specified. 

**Examples:**

* pass:q[`Period(days=2)`] indicates that the observation points are on every 
                other day. 
* pass:q[`Period(months=3, date_failover=DateFailover.FIRST_VALID_DAY_AFTER)`]
                indicates that the observation points are every 3 months on the same calendar 
                day as fetcher pass:q[`start`]. If the next observation point falls outside the particular 
                month, the observation point will be the first valid day 
                after the missing day in the month.
