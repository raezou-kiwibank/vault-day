= ActivationHookArguments
:status: hidden

pass:q[`ActivationHookArguments`]  

The hook arguments of pass:q[`activation_hook`].  

== Constructor:
pass:q[`ActivationHookArguments(*, effective_datetime)`]  

Constructs a new ActivationHookArguments object.  

[width="100%", options="header"]
|===
|name|type|description
|effective_datetime|pass:q[`datetime`]| The logical datetime the hook is being run against. Must be a timezone-aware UTC datetime using the ZoneInfo class. +

 When an account is opened, pass:q[`effective_datetime`] will be set to the pass:q[`opening_timestamp`] for /v1/accounts requests or pass:q[`activation_timestamp`] for /v2/accounts requests. The pass:q[`effective_datetime`] can optionally be backdated by setting these fields to a backdated value on the request to open the Account. If they are not backdated then they default to the date and time that the request is processed. 
|===
