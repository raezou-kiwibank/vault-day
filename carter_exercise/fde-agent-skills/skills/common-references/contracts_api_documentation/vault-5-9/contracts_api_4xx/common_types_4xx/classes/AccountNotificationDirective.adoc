= AccountNotificationDirective
:status: hidden

pass:q[`AccountNotificationDirective`]  


== Constructor:
pass:q[`AccountNotificationDirective(*, notification_type, notification_details)`]  


A Hook Directive that instructs the publication of a notification.
Notification must be defined in the
link:{baseURL}/smart_contracts/contracts_api_4xx/smart_contracts_api_reference4xx/metadata#notification_types[notification_types]{empty} list.  

[width="100%", options="header"]
|===
|name|type|description
|notification_type|pass:q[`str`]| The pass:q[`type`] of notification. Used to identify how a notification should be processed. 
|notification_details|pass:q[`Dict`][pass:q[`str`], pass:q[`str`]]| The information (key-value pairs of data) to be published with the notification. 
|===
